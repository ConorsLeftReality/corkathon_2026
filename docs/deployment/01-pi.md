# 1. Pi base

## Flash the SD card

Raspberry Pi Imager, **Raspberry Pi OS Lite (64-bit)**. It must be 64-bit: Piper's `onnxruntime` has no 32-bit build, and Dokku images are arm64. In the Imager settings set the hostname (the live Pi is `dialed-in-pi`), a user (`pi`), SSH on, the wifi network and country `IE`. A phone hotspot must be 2.4 GHz, since the Pi 3 has no 5 GHz radio (iPhone: Maximise Compatibility).

## Clone the repo

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/ConorsLeftReality/corkathon2026 ~/corkathon2026
cd ~/corkathon2026
```

## Phone LAN

The Pi is the router for the phone network: `eth0` is `10.99.99.1/24` with DHCP, DNS and NAT, and `wlan0` is the uplink. Calls keep working with no internet; only speech to text and the CRO download need it. The odd subnet avoids clashing with hotspots (`192.168.x`, `172.20.10.x`) and eduroam.

Plug the Pi's `eth0` into the switch, then:

```bash
sudo bash infra/pi/network.sh
```

When the DECT base is plugged in (step 2), pin its address by rerunning with its MAC. The live base is `00:00:5e:00:53:01`:

```bash
sudo bash infra/pi/network.sh 00:00:5e:00:53:01
```

Check with `ip -br addr` (`eth0` shows `10.99.99.1/24`) and `cat /var/lib/NetworkManager/dnsmasq-eth0.leases`. A captive portal wifi needs one browser sign-in from a laptop on the switch.

## Tailscale

Everything off the Pi (SSH, the sites, Zoiper, GitHub Actions) reaches it over Tailscale. Do not expose ports on the router or turn on Funnel.

```bash
curl -fsSL https://tailscale.com/install.sh | sh
# advertise the phone lan so Zoiper (and a laptop) can reach 10.99.99.1 from anywhere on the tailnet,
# and offer the Pi as an exit node so a device on the tailnet can send its internet traffic through it
echo 'net.ipv4.ip_forward = 1' | sudo tee /etc/sysctl.d/99-tailscale.conf && sudo sysctl -p /etc/sysctl.d/99-tailscale.conf
sudo tailscale up --advertise-routes=10.99.99.0/24 --advertise-exit-node
tailscale ip -4   # the live Pi is <pi tailscale ip>
```

SSH goes over the tailnet to the Pi's normal OpenSSH server with the key the Imager installed, so Tailscale SSH stays off.

Tailscale's MagicDNS points the Pi's `/etc/resolv.conf` at `100.100.100.100`, which forwards to whatever router the wifi gives it. Docker builds inherit that and fail with DNS errors when the router is slow, so step 3 gives Docker its own resolvers.

In the Tailscale admin console:

1. Approve the Pi's `10.99.99.0/24` subnet route and its exit node (Machines, the Pi, Edit route settings).
2. Create the tag `tag:corkathon-ci` and an OAuth client that can use it, for the deploys in step 5.
3. On the DNS page, turn on MagicDNS and HTTPS Certificates, so step 3 can serve the site at `https://<pi>.<tailnet>.ts.net`.

## Piper

Piper turns text into speech for the prompts and answers.

```bash
sudo apt install -y python3-pip ffmpeg flac alsa-utils
sudo pip install piper-tts --break-system-packages
sudo mkdir -p /opt/piper-voices && cd /opt/piper-voices
sudo python3 -m piper.download_voices en_GB-alan-low
echo "Hello from Dialed-In" | piper -m /opt/piper-voices/en_GB-alan-low.onnx -f /tmp/test.wav && aplay /tmp/test.wav
```

`which piper` should print `/usr/local/bin/piper`. Both `en_GB-alan-low.onnx` and `en_GB-alan-low.onnx.json` must be in `/opt/piper-voices`.

## Lock it down

The wifi the Pi joins is someone else's network, so nothing on it should reach the Pi. Once Tailscale works and you can SSH in over it with your key:

```bash
sudo bash infra/pi/harden.sh
```

It turns SSH passwords and root login off, loads `infra/pi/firewall.nft` (wlan0 gets only replies to traffic the Pi started, Tailscale and DHCP; eth0 and the tailnet are untouched) as the `dialed-in-firewall` service, stops Asterisk loading IAX2, DUNDi and UNISTIM, and turns on automatic Debian security updates. Rerun it after step 2 so the Asterisk part applies. Open a second SSH session before closing the first, in case the key is wrong.

Check from another device on the same wifi that `nc -zv <pi wifi ip> 22` and port `9000` time out, and that `ssh` over Tailscale still works. Kernel updates come from the Raspberry Pi repository, which automatic updates skip: run `sudo apt full-upgrade` and reboot now and then.
